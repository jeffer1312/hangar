---
titulo: O Claude ou o Codex consertam o servidor parado
tipo: novo
onde: desktop
sistema: linux, windows
experimente: Com o servidor desta máquina parado, abra Configurações → Status e toque em Consertar com agente.
animacao: consertar-com-agente
---

Quando o servidor desta máquina para, a tela Status mostra o motivo e um botão para o Claude ou o Codex instalados aqui consertarem sozinhos.

Você acompanha cada comando que o agente roda, pode parar a qualquer momento e, no fim, lê o que ele mudou. Se não der certo, a tela oferece o outro agente e copia o relatório para você mandar.
