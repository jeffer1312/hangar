---
titulo: Subagentes que terminam, lista que não pisca e worktrees limpas
tipo: correcao
onde: todos
---

Subagentes que já terminaram não aparecem mais como "rodando" para sempre, inclusive os abertos de dentro de um script no Code Mode, que agora mostram o relatório. A lista de sessões também parou de alternar entre "trabalhando" e "parada" a cada poucos segundos.

Também mudou: criar conversa numa worktree nova com um nome que já existe não dá mais erro, a branch ganha um número no fim; worktree aberta sem branch entra na limpeza quando o commit já está na base; a busca de repositórios termina em vez de avisar que não acabou; no celular, um comando como /compact mandado durante o trabalho não fica preso em "Na fila"; e no Windows a atualização tenta de novo ler os processos quando a máquina está sem memória livre.
