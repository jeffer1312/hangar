Um jeito novo de acompanhar a conversa, para experimentar: dá para ver de relance o que o agente faz agora, a falha aparece na própria linha e o Parar fica à vista mesmo enquanto você escreve.

A aba aberta fica discreta e a que espera sua resposta ganha destaque próprio. A sugestão de nome vira um cartão com os botões ao lado do texto. Na mesma página, o Code Mode do Claude Code (experimental) faz as novas sessões do Claude nascerem com ele; se ele já estiver ligado nos ajustes do Claude, a opção mostra isso.

Para voltar ao desenho de sempre, escolha Atual.
