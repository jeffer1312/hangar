---
titulo: O Computer Use se instala e se atualiza sozinho
tipo: melhoria
onde: desktop
experimente: Em Configurações > Computer Use, veja a versão instalada no passo Programa.
---

Não é mais preciso clicar em Instalar: o servidor baixa o programa do Computer Use e troca para cada versão nova sozinho, mesmo com sessões abertas. Com um computador cadastrado, ele já fica ativo nas sessões; se você desligar, continua desligado. Se a instalação falhar, a tela mostra o motivo, e numa máquina sem versão do programa ela diz que o recurso está indisponível.
